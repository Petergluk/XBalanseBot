## Введение
**XBalanseBot** — это асинхронный Telegram-бот на Python (`aiogram 3.x`, `psycopg3`, `APScheduler`, `Redis`), предназначенный для управления внутренней экономической системой закрытого сообщества («Пространство»). Бот обеспечивает учет балансов во внутренней валюте (`Ӫ` — орфы), мгновенные переводы, внутреннюю биржу товаров и услуг, автоматические награды за публикации с хэштегами, подписки на активности и события с автосписанием взносов, а также ежедневный демерредж.

## Основные Возможности
* **Личный баланс и история**: Учет в `Ӫ` с точностью `NUMERIC(12, 2)` и детализацией всех типов транзакций (`/balance`, `/history`).
* **Переводы P2P и в Фонд**: Мгновенные переводы между участниками и добровольные взносы в Фонд сообщества (`/send @username сумма`, `/send @fund сумма`).
* **Внутренняя Биржа (Offers)**: Пошаговый мастер публикации объявлений (`/offer` или кнопка в `/menu`) с фото, количеством, сроком действия и покупкой в 1 клик в группе.
* **Награды за хэштеги (Tag Rewards)**: Автоматическое начисление орфов за посты в группе с заданными хэштегами, проверкой длины текста, лимитами по периоду и привязкой к топикам.
* **Активности и События**: Каталог кружков/направлений (`/activity`) и календарь разовых/регулярных мероприятий (`/event`) с автоматическим списанием платы и разовым кредитом доверия (`grace_credit`).
* **Демерредж (Demurrage)**: Ежедневный налог на простой капитала (по умолчанию в `00:01 MSK`), перечисляемый в Фонд сообщества (`id = 0`).
* **Интеграция с Tribute**: Прием фиатных пополнений через защищенный идемпотентный вебхук `POST /webhook/tribute`.

## Архитектура Системы и Облачный Стек
Продакшен-инфраструктура развернута на связке **Koyeb + Supabase + Upstash**:
* **Koyeb (Compute / Web Service)**: Запускает Docker-контейнер от непривилегированного пользователя (`appuser`), автоматически выполняет `alembic upgrade head` перед стартом `main.py` и принимает вебхуки на порту `8080`.
* **Supabase (PostgreSQL 15+)**: Персистентное хранилище с включенным **Row-Level Security (RLS)** на всех таблицах схемы `public` (доступ к PostgREST API для ролей `anon` и `authenticated` закрыт; бот подключается через пул `psycopg_pool`).
* **Upstash (Serverless Redis с TLS `rediss://`)**: Хранение состояний `FSM` (`RedisStorage`) и кэширование активных правил хэштегов (`tag_rules:active`, TTL 60 сек с мгновенной инвалидацией при изменениях).

### Структура Кодовой Базы
* `main.py` — Точка входа, инициализация `Bot`, `Dispatcher`, `RedisStorage`, `APScheduler` и `aiohttp` вебхук-сервера.
* `app/db/` — Модульный слой доступа к БД (миксины `users.py`, `transactions.py`, `activities.py`, `events.py`, `offers.py`, `tags.py`, `settings.py`, объединенные в `app/database.py`).
* `app/handlers/` — Роутеры `common.py`, `user_commands.py`, `admin_commands.py`, `activity_handlers.py`, `event_handlers.py`, `offer_handlers.py`, `tag_reward_handler.py`.
* `app/services/` — Фоновые задачи планировщика (`scheduler_jobs.py`) и HTTP/Webhook сервер (`webhook_handler.py`).
* `app/lexicon.py`, `app/keyboards.py`, `app/callbacks.py`, `app/states.py` — Словари локализации, инлайн-клавиатуры, типизированные `CallbackData` и состояния FSM.

## Ключевые Концепции
* **Фонд Сообщества (`id = 0`, `@fund`)**: Специальный системный счет, аккумулирующий списания от демерреджа и добровольные переводы участников (`/send @fund сумма`). Администратор может распределять средства из Фонда участникам командой `/pay_from_fund @username сумма [комментарий]` (или `/fund`).
* **Эмиссия и Сжигание**: Welcome-бонусы, награды за хэштеги, пополнения через Tribute и `/add` являются чистой эмиссией (`from_user_id = 0` как системный маркер без уменьшения баланса Фонда). Оплата событий (`event_fee`) и `/rem` являются чистым сжиганием средств.
* **Кредит доверия (`grace_credit_used`)**: Позволяет участнику один раз уйти в минус при оплате события. Автоматически сбрасывается в `FALSE`, как только баланс участника снова становится `>= 0`.

## Установка и Запуск
1. **Клонируйте репозиторий и установите зависимости:**
   ```bash
   git clone https://github.com/Petergluk/XBalanseBot.git
   cd XBalanseBot
   poetry install
   ```
2. **Настройте переменные окружения (`.env`):**
   ```env
   BOT_TOKEN=your_telegram_bot_token
   MAIN_GROUP_ID=-1001234567890
   SUPER_ADMIN_ID=123456789
   DATABASE_URL=postgresql://postgres.[ref]:[pass]@aws-0-eu-central-1.pooler.supabase.com:5432/postgres
   REDIS_URL=rediss://default:[pass]@[endpoint].upstash.io:6379
   DEV_MODE=True
   WEBHOOK_HOST=your-app.koyeb.app
   WEBHOOK_SECRET_TOKEN=your_webhook_secret
   TRIBUTE_WEBHOOK_SECRET=your_tribute_secret
   ```
3. **Примените миграции Alembic (включая RLS и индексы):**
   ```bash
   poetry run alembic upgrade head
   ```
4. **Запустите бота:**
   ```bash
   poetry run python main.py
   ```

## Тестирование

## Руководство Пользователя
* `/start` — Регистрация в системе, ознакомление с правилами сообщества и получение персональной одноразовой ссылки в группу.
* `/menu` — Главное интерактивное меню бота (переводы, создание объявления, активности, ближайшие события, баланс, справка).
* `/balance` — Текущий баланс и сводка транзакций за последние 30 дней.
* `/history [дней]` — Детальная выписка по операциям за указанное число дней (переводы, покупки на бирже, награды за хэштеги, мероприятия, демерредж, выплаты из Фонда).
* `/send @username сумма [комментарий]` — Быстрый перевод орфов другому участнику или в Фонд (`/send @fund 100`). Вызов `/send` без аргументов запускает пошаговый диалог.
* `/offer` — Пошаговый мастер публикации объявления о продаже товара или услуги в группу/топик биржи.
* `/activity` — Просмотр направлений сообщества и подписка на них.
* `/event` — Расписание ближайших событий на 7 дней вперед с возможностью разовой записи или отмены.
* `/gdp` (или `/ввп`) — Макроэкономическая статистика сообщества: оборот за 7/30 дней, общая денежная масса и баланс Фонда.
* `/cancel` — Безопасный выход из любого пошагового диалога с очисткой временных сообщений.

## Руководство Администратора
* `/settings` — Главное меню настроек системы:
  * **📉 Настройки демерреджа**: Включение/выключение и установка ежедневной ставки процента.
  * **🎁 Welcome-бонус**: Сумма бонуса за вступление в группу и шаблон поздравительного сообщения.
  * **📝 Приветствия и шаблоны**: Редактирование приветствия в боте, в группе и шаблона напоминания о событиях (с кнопкой возврата к значению по умолчанию).
  * **🏷 Поощрения**: Управление правилами автоматических наград за хэштеги (`/list_tag_rules`, `/add_tag_rule`).
  * **📢 Настройка топиков**: Привязка топика супергруппы для публикаций биржи (`/set_market_thread` внутри нужной темы, `/get_thread_id` для проверки ID темы).
* **Управление балансами и Фондом**:
  * `/add @username сумма [комментарий]` — Начислить средства (эмиссия).
  * `/rem @username сумма [комментарий]` — Списать средства.
  * `/pay_from_fund @username сумма [комментарий]` (алиасы: `/fund`, `/fund_pay`) — Выплатить средства участнику из накоплений Фонда сообщества (`@fund`).
  * `/check @username` — Полная карточка участника (или `@fund`): Telegram ID, баланс, статус кредита доверия и последние 10 транзакций.
  * `/users [страница]` — Постраничный список всех участников и их балансов.
* **Управление активностями, событиями и рассылками**:
  * `/create_act` и `/create_event` — Пошаговые мастера создания активностей и событий (также доступны через инлайн-кнопки внутри `/activity`).
  * Внутри карточки каждой активности администратору доступны кнопки **«✏️ Редактировать»**, **«➕ Создать событие»**, **«👥 Список подписчиков»** и **«📢 Рассылка»** (мгновенная или отложенная по расписанию; отмена задачи — `/cancel_broadcast <job_id>`).
* **Управление ролями и тестирование**:
  * `/make_admin @username` / `/remove_admin @username` — Назначение и снятие прав администратора.
  * `/reset @username` — Полное каскадное удаление тестового пользователя и его истории для повторного прохождения онбординга с нуля.
  * `/gide` и `/test` — Встроенное руководство администратора и шпаргалка команд с готовыми примерами.
