# - ОБЩАЯ ИНФОРМАЦИЯ О ПРОЕКТЕ

## 1.1 Что это за проект?
**XBalanseBot** — это production-grade Telegram-бот на Python, предназначенный для управления внутренней экономикой сообщества. По сути это "банк в Telegram" с полным циклом: балансы пользователей, переводы, платные подписки на "активности" (кружки по интересам), события с автоматическим списанием, рынок (offer'ы), демередж (отрицательный процент на остаток), webhook-интеграция для пополнений через внешнюю систему (Tribute).

Целевая аудитория: закрытые Telegram-сообщества (чаты, клубы, учебные группы), которым нужна внутренняя валюта без привязки к реальным деньгам.

### Возможности:
- Внутренняя валюта "орфы" (Ӫ)
- Виртуальные балансы, P2P-переводы
- Активности (кружки) и события (разовые/регулярные) с автоплатежом
- Демерредж (ежедневный "отрицательный процент" на остаток, 1%)
- Маркетплейс (объявления о продаже/обмене)
- Награды за хэштеги в групповых чатах
- Welcome-бонус для новых участников
- Административная панель (управление настройками, пользователями)
- Интеграция с Tribute (пополнение баланса через вебхук)
- Рассылки подписчикам активностей



### Технологии:

Язык: Python 3.13.4
Telegram Framework: aiogram 3.x
База данных: PostgreSQL + psycopg3 (async pool)
Кэш/FSM: Redis
Планировщик: APScheduler 3.x
Миграции: Alembic
Веб-сервер: aiohttp (для webhook)
Контейнеризация: Docker
Deployment: Render, Koyeb

## 1.4 Как Это Работает?

### Пользовательский сценарий:

/start → регистрация в БД, welcome-бонус (1500 Ӫ)
/menu → главное меню с балансом
/send @user 100 → перевод орфов
Подписка на активности → уведомления о событиях
Автоматическое списание платы за события
Публикация контента с хэштегами → награды

### Административный сценарий:

/settings → настройка системы
/add @user 500 → начисление орфов
/create_act → создание активности
/create_event → создание события
Управление tag rules, рассылками
Фоновые процессы:

Демерредж: Ежедневный налог (1%) на положительные балансы
Оплата событий: Автоматическое списание по расписанию
Напоминания: Отправка за N минут до события
